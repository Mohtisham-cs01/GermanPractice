# GermanPractice

A simple web application for practicing German vocabulary.

## ✨ Features

*   Clean, minimal interface for language practice
*   Focused on helping you learn German effectively

## 🚀 Live Demo

You can try the application here:  
[https://mohtisham-cs01.github.io/GermanPractice/](https://mohtisham-cs01.github.io/GermanPractice/)

## 🛠️ Built With

*   HTML
*   CSS
*   JavaScript

## 📁 Project Structure

The main application is contained in `index.html`. Deployment is automated via a GitHub Actions workflow (`.github/workflows/static.yml`).
